# 🚀 PipelineGuard AI

An intelligent multi-agent system that monitors, diagnoses, and auto-heals data pipeline failures in real-time.

## 🔥 Features

* Real-time pipeline monitoring
* AI-based root cause analysis
* Automated failure healing
* Interactive dashboard

## 🛠 Tech Stack

* FastAPI
* LangGraph
* React
* Gemini  API

## ▶️ Run Locally

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn api:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🎯 Demo

Click "Inject Failure" to simulate pipeline failure and watch AI fix it automatically.
